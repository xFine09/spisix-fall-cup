Datos de un partido del cuadro

Una sola ruta de solo lectura que devuelve en JSON el cruce, la mappool de la ronda y los protects, bans y picks apuntados por el árbitro. No necesita login ni clave.

La ruta

GET__BASE_URL__/api/overlay?match=u1-6
  • Se puede pedir desde cualquier web o desde una fuente de navegador de OBS: lleva Access-Control-Allow-Origin: *.
  • Solo GET y sin cookies: no mandes credentials: "include".
  • La respuesta se guarda 5 segundos en caché (Cache-Control: public, max-age=5). Pedirla cada 5 segundos es suficiente; más a menudo no da datos más nuevos.

IDs de los partidos

El parámetro match es el ID del partido tal como sale en la web. Da igual en mayúsculas o minúsculas (U1-6 o u1-6); la respuesta siempre lo devuelve en minúsculas.

PartidosroundbestOf
u1-1 … u1-8octavos9
u2-1 … u2-4, l1-1 … l1-4cuartos9
u3-1, u3-2, l2-1 … l2-4, l3-1, l3-2semis11
u4-1, l4-1, l4-2, l5-1finals11
l6-1, gfgf13

u es el upper bracket y l el lower bracket.

  "bestOf": 9,
  "players": {
    "red":  { "id": 32031654, "username": "suutee" },
    "blue": { "id": 22443532, "username": "Ouwo Cronii" }
  },
  "pool": [
    { "slot": "NM1", "beatmap_id": 4956966, "data": { "artist": "…", "title": "…", "version": "…", "sr": 5.21, … } }
  ],
  "rundown": [
    { "actor": "RED",  "action": "PROTECT", "pick": "NM1" },
    { "actor": "BLUE", "action": "BAN",     "pick": "DT2" },
    { "actor": "RED",  "action": "PICK",    "pick": "HD1" }
  ]
}
CampoQué es
scheduledAtHora del partido en milisegundos desde 1970 (UTC), para new Date(scheduledAt). null si aún no tiene hora. El torneo va en hora de Madrid.
players.redEl jugador A del cruce, el que el árbitro pone en el equipo rojo con !mp team.
players.blueEl jugador B, en el equipo azul.
poolLos mapas de la ronda, ordenados por slot: NM, HD, HR, DT, FM y TB.
rundownProtects, bans y picks en el orden en que se apuntaron.

Cuándo cambia cada cosa

players

  • Un jugador que todavía no está decidido sale como null; por ejemplo, el ganador de un partido que aún no ha terminado.
  • Hasta que la organización publica los resultados de los clasificatorios, todos los jugadores salen como null, igual que en la web.

pool

  • Es [] hasta que se publica la mappool de esa ronda. En cuanto es pública, salen todos los mapas.
  • Para cada mapa: slot, beatmap_id y data.
  • data trae, entre otros: artist, title, version (la dificultad), creator, sr, bpm, length (en segundos), cs, ar, od, cover (imagen del set) y url (enlace al mapa). En HR y DT, SR, BPM, duración y stats ya vienen con el mod aplicado.
  • Puede traer más campos; ignora los que no uses y no des por hecho que todos existen en todos los mapas.

rundown

  • actor: RED o BLUE. action: PROTECT, BAN o PICK. pick: el slot (NM1, DT2…).
  • El pick del tiebreaker sale como { "actor": null, "action": "PICK", "pick": "TB" }: no lo elige ninguno de los dos.
  • Si el árbitro deshace algo, desaparece del rundown. No guardes el rundown anterior y añadas lo nuevo: sustituye la lista entera en cada petición.
  • Es [] si no hay nada apuntado. No incluye los rolls, ni el orden elegido, ni el marcador ni las puntuaciones.

Errores

Siempre en JSON, con { "error": "…" } y también con CORS:

CódigoCuándo
400Falta el parámetro match.
404Ese partido no existe (por ejemplo, u9-9).

Ejemplo en JavaScript

const URL_API = '__BASE_URL__/api/overlay?match=u1-6';

async function actualizar() {
  try {
    const res = await fetch(URL_API);
    const datos = await res.json();
    if (!res.ok) throw new Error(datos.error);
    const rojo = datos.players.red?.username ?? 'Por decidir';
    const azul = datos.players.blue?.username ?? 'Por decidir';
    // pintar rojo, azul, datos.pool y datos.rundown…
  } catch (e) {
    console.warn('Sin datos del partido:', e.message); // se reintenta en la siguiente vuelta
  }
}

actualizar();
setInterval(actualizar, 5000);
Los datos son los mismos que se ven en la web del torneo: nada de lo que devuelve la ruta es privado.
